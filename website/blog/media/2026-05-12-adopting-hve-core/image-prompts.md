## Image Generation Notes

All images should use:
- **Watercolor illustration style** (not photorealistic)
- **Pacific Northwest color palette**: evergreen green (#2F5233), slate blue (#4A5F7A), fog gray (#B8BFC6), warm wood (#8B7355), soft white
- **Composition**: balanced, not cluttered, with clear visual hierarchy
- **Metaphor integration**: technical concepts represented through tangible PNW imagery (tools, bridges, workshops, nature)
- **Mood**: contemplative, forward-looking, collaborative (not competitive)

File formats: PNG with transparent backgrounds where appropriate, 1200px wide for hero images, 800-1000px for diagrams.
